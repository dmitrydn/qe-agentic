# packages

Product code (Node.js / TypeScript). See `../intent.md` §5 and §12.

- `core/` — shared formats, evidence records, AI-provider interface
- `connectors/` — replaceable links to AI providers, requirement sources, technology stacks and test-result formats
- `capabilities/` — the five checks C1–C5, each standalone
- `cli/` — one command per capability
